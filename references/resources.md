
# Learning Resources

## GTFOBins

https://gtfobins.github.io/

A reference for understanding how Unix binaries may be abused in specific privilege contexts.

## GTFOBins: tar

https://gtfobins.github.io/gtfobins/tar/

The reference for GNU tar, including its documented execution contexts and prerequisites.

## GNU tar Manual

https://www.gnu.org/software/tar/manual/

Official documentation explaining archive creation, extraction, checkpoints, and other tar functionality.

## Sudo Documentation

https://www.sudo.ws/docs/

Documentation on sudo usage and configuration.

## Linux man-pages

https://man7.org/linux/man-pages/

Reference manuals for Linux commands, system calls, and administrative interfaces.

## OverTheWire: Bandit

https://overthewire.org/wargames/bandit/

A beginner-friendly Linux command-line learning resource.

## PortSwigger Web Security Academy

https://portswigger.net/web-security

Free training for learning broader web application security concepts.

## Practice Environment

Use a disposable virtual machine or an intentionally vulnerable lab that you own or are authorized to test.

Keep practice systems isolated from production networks and sensitive data.
